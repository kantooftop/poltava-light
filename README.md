# Полтава Світло (Черга 6.1) ⚡

Нативний Android-додаток для автоматичного відстеження графіків відключення світла та аварійних відключень (ГАВ / СГАВ) у Полтавській області (АТ «Полтаваобленерго»).

## Можливості
- **Спеціально для черги 6.1**: відображає поточний статус і таймлайн на день.
- **Термінові сповіщення про ГАВ / СГАВ**: з окремим каналом максимального пріоритету та вібрацією.
- **Сповіщення при зміні графіка**: якщо обленерго оновило години відключень.
- **Попередження перед відключенням**: за 30 хвилин до планового знеструмлення.
- **Фонова робота (WorkManager)**: перевірка кожні 15 хвилин навіть після перезавантаження телефону.
